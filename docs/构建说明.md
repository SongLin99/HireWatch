# 构建自己的桌面分享包

普通使用者请按 README 下载安装包。下面用于生成不要求接收者安装 Python 的原生应用。

## GitHub Actions

仓库提供自动回归测试和手动桌面构建。Fork 仓库后，在 Actions 启用工作流；点击对应工作流 → Run workflow。

- `Build macOS apps (manual)`：分别在原生 Apple Silicon / Intel Mac 环境构建 ZIP 与拖拽安装 DMG，并验证从镜像复制后启动。
- `Build Windows app (manual)`：生成带内置浏览器的 Windows 安装程序及便携包，并验证安装、重装和卸载保留数据。
- 成功产物在对应运行页面的 Artifacts，保留 7 天；下载后可长期保存。Actions 外层 ZIP 中的应用 ZIP 才是分享包。
- 工作流不配置 API 或推送凭据。Mac 构建会验证解压后的真实 App、浏览器、空设置、教程及菜单栏；Windows 构建会验证 EXE、空设置和教程。

## Windows 本机构建

使用 Python 3.12，在项目目录运行：

```powershell
py -3.12 -m venv .build-venv
.\.build-venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.build-venv\Scripts\python.exe scripts/build_windows.py
# 安装 Inno Setup 后生成安装程序
.\.build-venv\Scripts\python.exe scripts/build_windows_installer.py
```

推荐输出 `release/HireWatch-1.0.1-Windows-x64-Setup.exe`；另保留便携 ZIP。两者均内置 Python、采集浏览器、使用说明和依赖许可。安装程序使用 Inno Setup 编译，默认当前用户安装，卸载保留独立的数据目录。

## Mac 本机构建

需要 macOS 14+、匹配本机芯片的 Python 3.12，以及 Apple Command Line Tools。双击 `build_macos.command`，或在终端运行 `bash build_macos.command`。脚本会下载依赖与内置浏览器，运行测试、构建和自检。

- Apple 芯片：`release/HireWatch-1.0.1-macOS-AppleSilicon.zip`。
- Intel 芯片：`release/HireWatch-1.0.1-macOS-Intel.zip`。

运行 `python scripts/build_macos_dmg.py` 可生成与本机芯片对应的 DMG，并验证挂载、Applications 链接、拖拽复制后的应用和浏览器。GitHub 工作流会自动完成此步骤。

Mac 应用内置 Python 和采集浏览器。将解压后的 `.app` 拖到“应用程序”打开。默认只有 ad-hoc 签名，尚未完成 Apple Developer ID 签名和公证；从网上下载后可能被系统拦截，确认来源后按[苹果官方说明](https://support.apple.com/en-us/102445)处理，不应关闭系统安全保护。

## 安全核对

构建前运行 `python scripts/audit_public_source.py`；脚本检查发布文件中的凭据模式、个人路径和禁止收录的文件。构建脚本也会检查打包内容，并生成文件清单与 SHA256。审计通过不代表对第三方依赖、招聘源或实际运行行为做出了安全及法律保证。

只分享原始应用 ZIP，不加入个人数据。不要从自己正在使用的目录复制数据库、日志或密钥到包里。公开发布如需代码签名，使用自己的开发者身份，证书与私钥放在受控的 CI Secrets 中，不能提交到 Git。
