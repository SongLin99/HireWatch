# 三步开始使用

## 1. 打开应用

从 GitHub 下载源码 ZIP 并解压，安装 Python 3.12。

- Windows：双击 `start.cmd`。
- Mac：双击 `start.command`；缺少执行权限时，在终端进入文件夹运行 `bash start.command`。

首次联网安装环境和采集浏览器，以后复用。看板自动打开，并显示可跳过的新手教程。**此时不需要 Key，也不需要新微信号。**

## 2. 找到并收藏岗位

进入“设置与推送”选择来源；查看“监控来源”进度，或点击检查最新岗位。按公司、城市、关键词筛选，打开详情阅读原文，点击星标收藏。左侧“已收藏岗位”可统一查看。

首次扫描可能需要几分钟；某来源失败不影响查看其他已收录岗位。AI 尚未解析时，技能、岗位方向等高级字段可能缺失，先用公司、城市与关键词即可。是否仍在招以官网为准。

## 3. 按需要打开增强功能

**AI（可跳过）**：设置 → AI 服务与预算 → 选 DeepSeek / OpenRouter → 填自己的 Key 并保存 → 获取模型列表、选择模型 → 设定每日预算 → 按需开启自动解析并保存。

**AI 匹配（可跳过）**：填写技能、方向、城市、每周天数和时长。所有候选会区分已评分与未评分；失败项可后台补全，完成后刷新查看。

**微信（可跳过）**：订阅条件 → 选 Server酱或企业微信 → 填自己的推送凭据 → 保存并启用。首次采集不推送历史岗位。发送测试按钮会发出真实消息。

## 常见问题

**没有 Key 能用吗？** 能。采集、基础筛选、搜索、收藏与官网详情可用。AI 结构化字段和提示词匹配需要你自己的模型服务。

**为什么没有岗位？** 刚启动时先等待采集；检查监控来源是否成功。网站改版、网络或访问限制会造成失败，不代表公司没有实习岗位。

**安装失败？** 确认 Python 3.10+（推荐 3.12）且网络可以访问 Python 包源和 Playwright 浏览器下载。Mac 官方 Python 若出现证书错误，可使用其随附的 Install Certificates.command。保留错误信息，提交前去掉个人路径与凭据。

**为什么关闭网页还在运行？** 桌面入口通过托盘 / 菜单栏管理后台。需要停止时选择“退出招聘雷达（停止监控）”；源码 `run.py` 前台模式用 Ctrl+C 停止。

**会一直自动花钱吗？** 默认关闭 AI 自动解析，未配置密钥不会调用模型。手动匹配也会消耗模型额度；每天本机预算默认 5 美元，可以调低或停用，账单以服务商为准。

**升级和分享？** 个人数据与程序分开。备份前先退出应用；不要把自己的 `data/` 或数据库传给别人。原生 Mac 应用 ZIP 请保持原样，避免 Windows 解压后重压造成链接与权限丢失。
