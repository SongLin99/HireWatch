# 宣传图片

本目录的三张 PNG 使用内置 imagegen 生成，已人工检查主要文字。它们是功能示意海报，不是应用截图，不包含真实岗位、用户数据或服务凭据。主色与界面一致：深森林绿、浅青柠绿、暖白。

`interface.png` 与 `onboarding.png` 是在全新临时数据库、关闭采集和模型调用的环境中截取的真实界面，岗位与收藏均为空。可通过 `python scripts/verify_public_ui.py` 重新验证并截图。

| 文件 | 用途 |
| --- | --- |
| cover.png | 横版项目封面 / README 头图 |
| optional-ai.png | 方形功能介绍：不填 Key 也能使用，AI 可选 |
| get-started.png | 竖版三步上手海报 |

以下为生成时的最终提示词摘要，可用于后续保持视觉风格；完整英文提示词保存在 `prompts.json`。

1. **封面**：克制的中文开源软件宣传横图，暖白纸感、森林绿与浅青柠，3D 雷达和抽象岗位卡片。文字“招聘雷达 / HireWatch”“把实习机会，放进自己的工作台。”“官方招聘来源 / 多条件筛选 / 本地运行”“Windows / macOS · MIT 开源”，注明功能示意。
2. **可选 AI**：同风格方图，标题“先找实习，再按需连接 AI。”，对比“不填 Key：采集 · 搜索 · 收藏”与“填写自己的 Key：AI 解析 · 偏好匹配”。注明支持 DeepSeek / OpenRouter、AI 按所选服务商计费，注明功能示意。
3. **三步上手**：同风格竖图，“你的实习信息工作台。”，三个步骤“检查官方岗位 / 按条件筛选 / 收藏并跟进”。注明 Windows / macOS、首次自带教程、AI 与微信提醒可选，注明功能示意。

约束：不使用招聘公司标志，不编造岗位数量、评分或用户数，不承诺全量覆盖、录用或秒级通知，不展示密钥、个人资料、二维码或未知网址。
